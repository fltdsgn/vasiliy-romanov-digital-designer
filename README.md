# Vasiliy Romanov — portfolio 2026

Отдельный проект нового портфолио. Макет: [Figma](https://www.figma.com/design/wqThLgYp3UiS7IgW8H105N/%D0%9F%D0%BE%D1%80%D1%82%D1%84%D0%BE%D0%BB%D0%B8%D0%BE-2026?node-id=440-39269).

## Запуск

Откройте `index.html` в браузере. Проект пока без сборщика и внешних зависимостей.

## Структура

- `index.html`, `styles.css`, `script.js` — страница, оформление и поведение.
- `assets/fonts/` — локальный шрифт.
- `assets/images/` — оптимизированные изображения WebP.
- `assets/video/showreel-teaser.webm` — беззвучный тизер на 8 секунд с резкими склейками, зациклен в превью страницы.
- `assets/video/showreel.webm` — полная версия шоурила, открывается поверх страницы с управлением и звуком.

## Оптимизация медиа

Запустите `.\optimize-media.ps1`, чтобы создать версии WebP и WebM и обновить ссылки сайта. Исходные MP4/JPG/PNG остаются рядом, локально; Git игнорирует их и публикует оптимизированные файлы. Скрипт повторно обрабатывает только исходники, изменённые после последней конвертации.

На компьютере архивная борда бесконечно перемещается мышью во все стороны, её позиция сохраняется на текущем устройстве. На телефоне проекты перестраиваются в обычную сетку. Галерея концептов повторяется по диагонали, а видео запускаются по мере просмотра.

Проекты «Рекап» и «Шоурил» использовались только как источники механик и материалов. PDF-резюме, контактные ссылки и подписи архивных проектов добавлены в сайт.
