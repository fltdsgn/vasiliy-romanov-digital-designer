# PixelFX exports

Generated locally from https://github.com/patch-gg/pixelfx using its `tools/render.mjs --sheet` exporter.

Included effects: bullet-tracer, sword-slash, hit-spark, hit-flash, emp-blast, energy-core, hologram, laser-grid, heart-lost, glitch-wipe, pixel-dissolve.

Atlas JSON files retain the per-frame timings, pivot and frame dimensions from the exporter.
